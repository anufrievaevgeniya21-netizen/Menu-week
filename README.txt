МЕНЮ НА НЕДЕЛЮ — обновлённая версия для установки на телефон

Загрузите в корень GitHub-репозитория все файлы и папку icons, заменив старые файлы:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png
- icons/icon-maskable-512.png

Затем откройте GitHub Pages по HTTPS. Если приложение уже было добавлено на главный экран, удалите старый ярлык/приложение и установите заново после обновления сайта.
Данные приложения сохраняются локально в браузере устройства. Данные на компьютере автоматически на телефон не переносятся; для переноса используйте экспорт/импорт в разделе «Рецепты».
