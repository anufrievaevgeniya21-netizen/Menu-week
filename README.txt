МЕНЮ НА НЕДЕЛЮ — мобильное веб-приложение

Файлы:
- index.html — приложение
- manifest.webmanifest — настройки установки
- sw.js — кэш для офлайн-открытия после первого посещения

Быстрый просмотр:
Откройте index.html в браузере на компьютере или телефоне. Локальный файл подходит для тестирования, но установка как полноценного PWA обычно требует HTTPS-хостинга.

Установка на телефон:
1. Разместите все три файла в одной папке на статическом HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте HTTPS-ссылку на телефоне.
3. Android/Chrome: меню ⋮ → «Установить приложение» или «Добавить на главный экран».
4. iPhone/Safari: «Поделиться» → «На экран Домой».
5. Данные сохраняются в локальном хранилище браузера на устройстве. В разделе «Рецепты» регулярно делайте «Экспорт данных» — JSON-файл можно импортировать на другом устройстве.

Формулы закупки: количество каждого ингредиента в рецепте трактуется как количество на 2 порции. В меню одинаковые блюда суммируются; одинаковые продукты объединяются по названию и единице измерения.
